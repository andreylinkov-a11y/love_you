# Проверка «Сада чудес»

Перед объединением режима необходимо подтвердить:

- стартовое поле не содержит готовых совпадений;
- на стартовом поле существует хотя бы один допустимый ход;
- диагональные и несмежные перестановки отклоняются;
- неверная перестановка не уменьшает число ходов;
- после удаления фишки падают сверху без пустых клеток;
- каскадные совпадения учитываются последовательно;
- поле без возможных ходов автоматически перемешивается;
- цель уровня растёт, число ходов не опускается ниже безопасного минимума;
- прогресс уровня сохраняется после перезапуска приложения;
- игровое поле помещается на экраны разных пропорций;
- свайпы работают в четырёх направлениях и не вызывают системного ripple;
- любовь начисляется только один раз за завершённый уровень;
- APK собирается в GitHub Actions без ошибок.
