# Я тебя люблю ❤️

Простое красивое Android-приложение на Kotlin и Jetpack Compose.

## Что внутри

- анимированное сердце;
- тёплые фразы, меняющиеся по нажатию;
- современный нежный дизайн;
- автоматическая сборка APK через GitHub Actions.

## Как получить APK

1. Откройте вкладку **Actions** в GitHub.
2. Выберите последний запуск **Build Android APK**.
3. Внизу страницы скачайте артефакт **love-you-debug-apk**.
4. Распакуйте архив и установите `app-debug.apk` на Android.

Минимальная версия Android: 7.0 (API 24).
